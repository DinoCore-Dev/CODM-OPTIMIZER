What this phone supports

    Anything marked unsupported is simply not exposed by this kernel, so the module leaves it alone instead of pretending.

    How it works

    While Call of Duty: Mobile is in the foreground the engine raises the CPU ramp speed, keeps a floor under the GPU clock, holds the panel at its highest refresh rate and asks Android for performance mode. When the game leaves the screen, or the phone gets warm, every value is put back exactly as it was.

    Nothing is written to the game: no file edits, no memory patching, no anti-cheat tricks. Only system tunables are used, which is why uninstalling really does undo it.
